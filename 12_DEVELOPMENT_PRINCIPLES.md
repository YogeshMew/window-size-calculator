# Development Principles

Code should be written as if this project will exist for ten years.

---

Prefer composition over duplication.

Prefer reusable modules over page-specific logic.

Prefer configuration over hardcoding.

Prefer semantic HTML.

Prefer accessibility.

Prefer static rendering.

Prefer maintainability over shortcuts.

---

Performance Budget

JavaScript only where required.

Lazy load non-critical assets.

Optimize SVGs.

Optimize fonts.

Keep Core Web Vitals excellent.

---

Testing

Every calculator should include

unit tests

edge cases

validation tests

accessibility review

mobile review
