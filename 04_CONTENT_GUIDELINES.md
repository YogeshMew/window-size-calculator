# Content Guidelines

Every page should solve the user's problem.

Never write filler.

Never write generic AI text.

---

Every calculator page should include

Introduction

Who this tool is for

How to use

Measurement instructions

Formula

Worked examples

Common mistakes

Professional tips

FAQ

Related tools

Related guides

Related charts

---

Writing Style

Simple English

Short paragraphs

No keyword stuffing

No repetition

Explain technical terms

Avoid unnecessary jargon

---

Trust

Author

Last Updated

Calculation Methodology

Sources

Version Number

Disclaimer where required

---

Examples

Always include

Typical house example

Apartment example

Contractor example

Edge cases

---

Tables

Prefer tables over long paragraphs whenever useful.

---

Illustrations

Prefer diagrams over text whenever possible.

---

Goal

Users should finish reading without needing another website.
