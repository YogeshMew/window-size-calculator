# WindowMetrics Design Principles

WindowMetrics should feel calm, trustworthy, and professional.

Users should immediately feel they are using a precision tool rather than a marketing website.

---

## Core Principles

Clarity over decoration.

Whitespace over clutter.

Guidance over complexity.

Confidence over cleverness.

Accessibility before aesthetics.

Performance before animations.

---

## Visual Personality

Think

Vercel

Linear

Stripe Docs

Apple Support

Notion

GitHub Docs

Do NOT imitate their layouts.

Instead, emulate the feeling:

Professional

Minimal

Fast

Precise

Highly readable

---

## User Experience

Every page should reduce uncertainty.

Users should always know

where they are

what to do next

why the result matters

what action to take

---

## Calculator Philosophy

Inputs should feel conversational.

Outputs should feel like advice.

Never dump numbers.

Always explain them.

---

## Mobile First

Assume users are standing next to a window.

Everything should work comfortably with one hand.

Large touch targets.

Sticky result summary when useful.

No unnecessary scrolling between input and result.

---

## Trust

Never exaggerate.

Never use fake urgency.

Never recommend products without explanation.

Always explain assumptions.

Always explain limitations.
